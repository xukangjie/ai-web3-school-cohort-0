## 📚 今日学习内容

### 阅读内容：Prompt 工程

#### 核心理解

> Prompt 是告诉大模型我的需求，让他按照我的要求来输出。
> 我的要求里面需要包含：任务目标、可用信息、输出格式、安全限制和边界设置。
> 它是人和模型之间的桥梁/接口。

#### 知识点

| 概念 | 我的理解 |
|------|---------|
| **Instruction** | 明确的任务指令，告诉模型要做什么 |
| **Few-shot** | 给例子，让模型按照示例格式输出 |
| **Structured Output** | 规定输出格式，比如 JSON、表格等 |
| **Prompt Injection** | 恶意输入劫持模型 — 普通用户不需要太担心这个，这是生产环境大规模落地才要重点防范的 |

#### 关于 Prompt Injection 的个人看法

> Prompt Injection 主要是需要真实落地大规模应用的需求才要认真重视的。
> 普通用户只需要基本的防范意识：**不要明文写入 key、密码等敏感信息。**
> 真正的安全边界应该由代码、权限和校验来承担，不能依赖 Prompt 作为安全屏障。

---

## 💡 思考与收获

### 我（学员）对 Prompt 的理解

> **Prompt ≈ 给大模型的一份"任务说明书"**
>
> 不是魔法咒语，不是越长越好。而是把模糊需求变成模型能稳定执行的工作说明。
> 好的 Prompt 让模型在不确定时主动停下来问，而不是自信地编造答案。

### 与其他概念的关联

- 之前学 LLM 时已经知道「模型会编造，所以要核查」
- 今天学 Prompt 后更清楚：**Prompt 可以约束模型的输出边界，但不能替代人的判断**
- LLM 是概率模型 → Prompt 就是引导它输出高概率正确结果的方法
