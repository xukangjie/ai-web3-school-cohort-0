# Handbook Feedback

> 学习过程中发现的 Handbook 问题、卡点、建议，统一整理在此目录。
> 每条 feedback 尽量包含：页面链接 + 问题描述 + 建议改法 + 发现来源。

## 提交流程

1. 在阅读 Handbook 时遇到问题，新建 `YYYY-MM-DD-topic.md` 文件
2. 格式参考下方模板
3. 定期汇总提交到 GitHub 或直接向 Handbook 提 PR

---

## Feedback 模板

```markdown
# YYYY-MM-DD - [主题]

## 页面链接

https://aiweb3.school/zh/handbook/xxx/xxx/

## 问题类型

- [ ] 概念不清楚
- [ ] 错别字/语法
- [ ] 资料过期
- [ ] 结构建议
- [ ] 缺少内容
- [ ] 其他

## 问题描述

（请具体描述）

## 建议改法

（如有具体建议）

## 来源

- 学习阶段：第 X 周
- 相关概念：
```
